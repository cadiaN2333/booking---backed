# 全局场馆推荐与平台审核实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 按任务逐项执行。步骤使用复选框（- [ ]）跟踪。

**目标：** 实现根据顾客需求推荐场馆、场地和可预约时间，并提供商家管理与管理员审核自动上架闭环。

**架构：** 通过审核状态和上架状态分离内容生命周期；后端强制执行角色、商家归属和可预约库存约束。全局推荐以规则候选为权威，PgVector 与 ChatModel 只增强公开资料理由；顾客点击推荐后进入原有场地日历和预约事务。

**技术栈：** Java 17、Spring Boot、MyBatis-Plus、MySQL、Spring AI、PgVector、Vue 3、TypeScript、Element Plus、Vitest。
