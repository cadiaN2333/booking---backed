# 当前日期智能时段推荐实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 按任务逐项执行。步骤使用复选框跟踪。

**目标：** 在顾客端当前场地、当前日期的日历页中，提供最多三条可预约时段推荐；规则筛选是权威，PgVector 与聊天模型仅增强理由，异常时稳定降级。

**架构：** `SlotService` 提供时段读模型，推荐服务只保留 `available > 0` 候选并完成确定性排序。语义服务只能读取 `courtId` 对应的公开向量文档，并只能为已验证候选生成理由。前端面板置于日历工具栏下方，卡片点击复用既有 `book(slot)`。

**技术栈：** Java 17、Spring Boot、Spring AI、PgVector、JUnit 5、Mockito、Vue 3、TypeScript、Element Plus、Vitest、Vue Test Utils。

- [x] **步骤 3：实现最小契约、排序服务和 HTTP 入口。**

```java
public record SlotRecommendationRequest(
    @NotNull @Positive Long courtId, @NotNull LocalDate date,
    @Size(max = 300) String query, @Size(max = 4) Set<RecommendationTag> tags,
    @Min(1) @Max(3) Integer limit) {
  public int resolvedLimit() { return limit == null ? 3 : limit; }
}

public SlotRecommendationResponse recommend(SlotRecommendationRequest request) {
  List<SlotVO> candidates = slotService.listByCourtAndDate(request.courtId(), request.date()).stream()
      .filter(slot -> slot.getAvailable() > 0).toList();
  return new SlotRecommendationResponse(rank(candidates, request), true);
}
```

标签枚举固定为 `EVENING`、`EARLIEST`、`CAPACITY`、`QUIET`。`EVENING` 对 18:00–21:59 加分，`EARLIEST` 对更早开始时间加分，`CAPACITY` 对更高余量加分；并列项按开始时间、时段 ID 升序。`QUIET` 在本任务不改变规则分数。入口为 `POST /recommendations/slots`，返回既有 `Result.ok(...)`。
